# =============================================================
# TRINETRA AI — Python Dependencies
# Phase 1: Core Flask app, database, deployment server.
# Phase 3: Message + URL scam detection (TF-IDF / Random Forest).
# Phase 4: QR Code Scanner (OpenCV) + Voice Scam Detection (Whisper).
# Phase 5: Fake Payment Screenshot Detection (Tesseract OCR).
# Phase 6: Cyber Safety Knowledge Hub + PDF Report Generator (ReportLab).
# Phase 7: Authentication, light mode, deployment hardening.
#
# All core modules from the project spec are implemented.
#
# System requirements for Phase 4:
#   - ffmpeg must be installed and on PATH (required by Whisper to
#     decode audio). Install via `apt install ffmpeg` (Linux),
#     `brew install ffmpeg` (macOS), or see ffmpeg.org (Windows).
#   - No extra system library is needed for QR decoding — it uses
#     OpenCV's built-in QRCodeDetector, not pyzbar/libzbar.
#   - openai-whisper pulls in PyTorch (large download, ~500MB+) and
#     downloads its model checkpoint on first use (~75MB for "tiny",
#     configurable via WHISPER_MODEL_SIZE in .env). Both require
#     internet access and meaningful disk space the first time.
#
# System requirements for Phase 5:
#   - Tesseract OCR must be installed and on PATH. Install via
#     `apt install tesseract-ocr` (Linux), `brew install tesseract`
#     (macOS), or the installer at github.com/UB-Mannheim/tesseract
#     (Windows). If it isn't on PATH, set TESSERACT_CMD in your .env
#     to the full path of the tesseract executable.
# =============================================================
